# SQL 查询台交互优化（第一批）

本轮以 master `7508621013b5d941a349e6e88e308d1cd12525e7` 为基线，仅修改工作台 SQL 查询台的前端交互，不修改数据库结构、查询接口、只读账号配置或公共 SQL 的访问权限，也不新增前端依赖。

## 已实现

- 执行时固定 SQL、行数上限、超时、执行范围和开始时间；成功与失败均按实际提交内容记录。连续快捷键不会重复提交。
- 切换查询或关闭结果后，旧请求的成功/失败不再污染当前页面。单次执行尚未结束前仍禁止再次提交，不伪装成已经取消后端查询。
- 修改已保存 SQL 自动创建带来源的工作副本；保存仍更新原记录。切换前同步保护尚未被 Vue watcher 写入的内容。
- 保存操作也使用快照；请求返回时不删除另一个窗口的草稿、不覆盖保存过程中更新的编辑器内容或保存表单。
- 清空历史保留全部草稿和数据库中已保存的 SQL；最多保留最近 50 次执行，不再用执行历史上限淘汰草稿。无标题记录显示 SQL 摘要。
- 原“运行查询”按钮及 Ctrl/Cmd+Enter 执行选区（无选区时为当前语句）；新增“运行当前语句”“运行全部”，Ctrl/Cmd+Shift+Enter 执行完整脚本。Ctrl/Cmd+S 打开保存。
- 提供正在执行的等待时间、修改后结果过期提示、执行 SQL 快照和执行记录窗口。包含 USE / 会话变量依赖的脚本须使用“运行全部”。
- 双击结果单元格查看长文本、复制原值或整行；支持复制当前页。整行/整页的 TSV 复制对公式样式字符串加前导单引号，单元格原值复制不改内容。
- 明确截断行数以及分页、复制、导出的范围；截断或结果过期时导出二次确认。确认过程中切换了结果则不会误导出另一个查询。
- 可收起右侧历史区域。浏览器存储失败不会把成功查询标成失败，会提示并在离开时保护尚未落盘的内容。

## 实现组织

`SqlQuery.vue` 继续作为原编辑器、结果表格、保存/公共池对话框和 XLSX 导出的唯一实现，不复制其模板。实际路由入口 `SqlQueryResultExpand.vue` 改为组合外壳；`query-workbench.js` 中的扩展组件集中管理快照、草稿和执行边界，并保留原有结果区域自动展开行为。新增文本覆盖简体中文、繁体中文及英文。

SQL 扫描器只定位语句，不承担只读校验或安全授权。它匹配当前后端的 MySQL 风格引号、转义和注释规则，不承诺支持 DELIMITER、存储程序体或与当前后端不同的 SQL mode。
